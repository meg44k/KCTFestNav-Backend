# ロールベースアクセス制御 (RBAC) 権限一覧

バックエンドAPIにおける各ロール（役職）が実行可能な操作の一覧です。
現在のユースケース層（Usecase）に実装されている権限チェックロジックに基づいています。

## ロールの種類
- **Admin**: 管理者（運営委員など）
- **Gakuseikai**: 学生会
- **Student**: 企画担当者（学生）
- **Member**: 一般ユーザー / その他
- **Guest**: 未ログイン（トークンなし）

---
