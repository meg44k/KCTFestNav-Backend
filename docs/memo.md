# KCTFestNav

## やりたいこと
- 高専祭のナビゲーションサイトを作りたい

## 実装したいこと
- 二次元の高専マップ
- 三次元の高専マップ(前回作ったような)
- 現在地をピンで表示(2D/3D両者とも)
- イベント/展示が開催されている場所をわかりやすく表示
- 現在行われているライブを表示
- 各クラス、展示ひ物、飲食ブースの混雑度合いを表示
- 各クラスで何が行われているかを表示

## 実現したいことをさらに細かく
### 二次元のマップ
- 二次元のマップは既に学校側から二次元マップの画像データが配布されるため、現在地を表示するだけでいい。

### 三次元のマップ
- 二次元のマップだと、展示が行われている階がわかりづらいため、三次元で表示させる。
- 前回作ったときはMinecraftの3Dデータを用いた
- 全然3Dのモデルは変えてもい

### 行われているライブ表示
- 混雑度などにも通ずるが、運営委員の方に現在行われているライブを選択してもらって、バックエンドのほうから管理するつもり。
- 他のやり方があればそちらでも可。

### 混雑度
- 上に同じ。ただ、他のクラス、展示物の混雑度を勝手にいじれないようにしたい。

### 各クラスで何が行われているかを表示
- これは普通に静的に置いておくだけでいい

## 技術的な面
- フロントエンドは何でもいい。
- バックエンドにはGoを用いようと考えている。
- DBも特に考えていない。
